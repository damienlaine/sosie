# Bienvenue

[INTRO] Bienvenue dans Sosie ! Ce petit projet de démonstration compte cinq répliques.

[MICRO] Appuyez sur Espace pour enregistrer cette réplique, puis encore sur Espace pour vous arrêter.

[SYNTH] Pas envie de parler ? Appuyez sur S : une voix de synthèse dira cette phrase à votre place.

# Et ensuite

[RYTHMO] En mode Rythmo, le texte défile : dites chaque mot au moment où il passe la barre.

[FIN] La piste voix est prête dans le dossier export du projet. À vous de jouer !
